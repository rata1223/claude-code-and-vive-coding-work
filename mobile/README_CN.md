# KIS 自动交易 — 移动端

<p align="right"><a href="README.md">한국어</a></p>

韩国投资证券（KIS）自动交易平台的移动端与轻量 Web 客户端，基于 **Vue 3 + Vite + Capacitor 6**。
同一套 Web 应用可封装为 Android/iOS 原生壳，也可作为 H5 直接部署；与 Web 端（`../frontend`）共享页面与 Store 代码。

服务器地址、开发、原生构建与签名的说明见 [README.md](README.md)（韩文）以及仓库根目录的 `CLAUDE.md`。

## 来源与许可

本应用基于 QuantDinger-Mobile（源码可见许可，见 [`LICENSE`](LICENSE)）。
